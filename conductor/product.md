# Product Definition: SMBDL Quiz & Simulation Web (MVP)

## Vision
Web aplikasi lokal berbasis PHP 8.2 + MySQL (XAMPP) untuk membantu mahasiswa Sistem Informasi (SI167) menguasai materi Sistem Manajemen Basis Data Lanjut (Modul 1–5) melalui kuis terstruktur dan simulasi sandbox `db_penjualan_lab`.

## Core Modules (5 Modul)
1. Modul 1: Konsep Aplikasi DB & Normalisasi (`UNF -> 1NF -> 2NF -> 3NF`)
2. Modul 2: Physical Design, Batasan Integritas & DDL/DML/Select
3. Modul 3: JOIN, VIEW & Control Flow (`CASE`, `IF`, `IFNULL`, `NULLIF`, Alias)
4. Modul 4: UDF (`SELECT fc...()`), Stored Procedure (`CALL proc...()`), & `CURSOR`
5. Modul 5: Database Trigger (`BEFORE/AFTER`, `NEW/OLD`) + Reset Snapshot
6. Fitur Tambahan: Catatan / Materi Tambahan per Modul (`app_custom_modules`)
